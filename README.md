# Art Whisper

**Голосовой ввод текста для Windows.** Зажимаете клавишу — говорите — отпускаете: распознанный текст оказывается под курсором. Всё распознавание выполняется локально на вашем компьютере — ни одного байта аудио в облако.

Программа представляет собой один `.exe` файл (~170 МБ) без установки, драйверов и внешних зависимостей: Python не нужен, интернет после первой настройки не нужен.

---

## Возможности

- **Диктовка по горячей клавише** — правая `Ctrl` по умолчанию: зажали, проговорили, отпустили.
- **Индикатор у курсора** — цветной кружок, следующий за мышью:
  - 🔴 красный — идёт запись;
  - 🔵 синий — идёт распознавание;
  - 🟢 зелёный (вспышка ~1,2 с) — текст распознан и вставлен.
- **Полностью локальная работа** — движок [whisper.cpp](https://github.com/ggerganov/whisper.cpp) (портирован в C# через [Whisper.net](https://github.com/sandrohanea/whisper.net)), модели ggml крутятся на вашем CPU.
- **Модели на выбор** — `tiny` (быстро, для слабых ПК), `base`, `small` (баланс, по умолчанию), `medium` (максимум качества).
- **Одноэкземплярность** — повторный запуск exe при работающей программе ничего не делает.
- **Авто-вставка** — текст сразу вставляется в активное поле (отключается в меню трея).
- **Нормализация громкости** — тихий микрофон больше не проблема.
- **Защита от «галлюцинаций»** — программа измеряет уровень записи: на тишину Whisper не запускается, а вы получаете предупреждение с диагностикой микрофона.
- **Трей + окно статуса** — индикатор рядом с часами, настройки по правому клику, окно со статусом запуска и кнопкой проверки микрофона.
- **Подпись кода** — exe подписан сертификатом «Art Whisper» (самоподписанный; скрипт установки в комплекте).
- **Ведение журнала** — `%LOCALAPPDATA%\ArtWhisper\art-whisper.log`.

## Системные требования

- Windows 10 / 11 (64-bit).
- Микрофон.
- ~500 МБ свободного места (программа + модель `small`).

## Установка и запуск

1. Скачайте `ArtWhisper.zip` из [Releases](../../releases) и распакуйте в любую папку.
2. Один раз запустите `install-cert.bat` — установит сертификат издателя (права администратора не нужны; после этого Windows показывает издателя «Art Whisper»).
3. Запустите `ArtWhisper.exe`. Появится окно со строками статуса.

### Установка модели распознавания

При первом запуске программа скачает модель `small` (~466 МБ) сама. Если ваш провайдер блокирует серверы загрузки, установите модель вручную:

1. Скачайте три архива `ArtWhisper-model-small-pNof3.zip` из [Releases](../../releases) и распакуйте в одну папку.
2. Запустите `join.bat` — он склеит части в `ggml-small.bin` и положит её в `%LOCALAPPDATA%\ArtWhisper\models\`.

Ручной вариант: `copy /b ggml-small.bin.part1 + ggml-small.bin.part2 + ggml-small.bin.part3 ggml-small.bin`, затем скопировать `ggml-small.bin` в `%LOCALAPPDATA%\ArtWhisper\models\`.

Или скачать модель напрямую: [ggml-small.bin](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin).

## Использование

1. Установите курсор в любое поле ввода.
2. **Зажмите правый `Ctrl`** и говорите.
3. **Отпустите** — через 1–3 секунды текст появится под курсором.

Правый клик по иконке в трее — настройки:

| Пункт меню | Действие |
|---|---|
| Показать окно | Открыть окно статуса |
| Модель распознавания | tiny / base / small / medium |
| Авто-вставка текста | вкл/выкл автоматическую вставку |
| Создать ярлык на рабочем столе | создаёт .lnk |
| Открыть журнал | лог работы |
| Выход | завершить программу |

## Где что лежит

| Что | Где |
|---|---|
| Модель | `%LOCALAPPDATA%\ArtWhisper\models\ggml-*.bin` |
| Настройки | `%LOCALAPPDATA%\ArtWhisper\config.json` |
| Журнал | `%LOCALAPPDATA%\ArtWhisper\art-whisper.log` |

## Устранение неполадок

- **Вставляется «Редактор субтитров…» вместо сказанного** — микрофон записал тишину, а Whisper «дорисовал» текст (известная особенность). Программа теперь сама отсекает тишину и показывает предупреждение. Проверьте: Параметры → Конфиденциальность → Микрофон (доступ разрешён?), громкость записи микрофона, правильное устройство по умолчанию. Кнопка «Проверить микрофон» в окне программы покажет уровень записи.
- **Иконки в трее не видно** — Windows 11 прячет новые значки за стрелкой «^» рядом с часами.
- **SmartScreen предупреждает** — это нормально для самоподписанного сертификата: «Подробнее» → «Выполнить в любом случае». На других ПК установите `ArtWhisper-cert.cer` через install-cert.bat.
- **Распознавание медленное** — выберите модель `tiny` или `base` в меню трея.
- **В играх/окнах от администратора не вставляется** — запустите Art Whisper тоже от имени администратора.
- **Диагностика** — пришлите `%LOCALAPPDATA%\ArtWhisper\art-whisper.log`.

## Сборка из исходников

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download).

```bash
git clone https://github.com/paukchoice/ArtWhisper.git
cd ArtWhisper/src

# Нативные библиотеки whisper.cpp — достаём из пакета Whisper.net.Runtime:
curl -L -o wr.nupkg https://api.nuget.org/v3-flatcontainer/whisper.net.runtime/1.9.1/whisper.net.runtime.1.9.1.nupkg
# (nupkg — это zip; извлеките из него build/win-x64/*.dll в src/runtimes-win-x64/)

dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:IncludeAllContentForSelfExtract=true
# Готовый exe: src/bin/Release/net8.0-windows/win-x64/publish/ArtWhisper.exe
```

> Почему `runtimes-win-x64` лежит рядом с исходниками: в single-file публикации нативные ассеты Whisper.net.Runtime не попадают в бандл автоматически, поэтому они подключены в `.csproj` явно (`Content` + `TargetPath`), а рядом с проектом должны лежать сами dll.

## Архитектура

- `Program.cs` — всё приложение (~750 строк): winmm-запись с микрофона (16 кГц, моно), кольцевые буферы, PTT-опрос `GetAsyncKeyState`, overlay-форма, трей, скачивание моделей, whisper-инференс.
- Мьютекс `ArtWhisper_SingleInstance` — защита от дубликатов процессов.
- Порог тишины 0.8 % пиковой амплитуды + нормализация до 95 % — защита от галлюцинаций на пустом аудио.
